### 🔴 清单一：V1.0 必做（核心闭环，共8项）
> **原则**：必须能跑通 **“选题 → 生成辩论稿 → 录音 → AI评分 → 看前后对比数据”** 这条完整链路。所有功能必须在6周内完成。

| 序号 | 原功能名 | **辩论化改造后的具体实现** | 开发量评估 |
| :--- | :--- | :--- | :--- |
| **2** | 定题演讲训练 | 改为 **“AI立论脚手架”**。不负责润色华丽辞藻，而是帮学生生成**“论点-论据-论证”**的三段式逻辑骨架。 | 中（核心） |
| **3** | AI评估报告 | **保留并强化**。评分维度改为：**逻辑相关性（Logic）**、**论据充分性（Evidence）**、发音、流利度。去除“肢体语言”等虚标。 | 中（核心） |
| **4** | 历史记录 | **保留**。按时间倒序查看每次练习的录音和AI评分详情。 | 低（简单） |
| **5** | 成长轨迹 | **保留（杀手锏）**。使用ECharts绘制**双雷达图**，清晰对比“首次练习”与“最近练习”的五维能力提升。 | 低（复用ECharts） |
| **6** | 语音转文字 | **降级附带功能**。不单独调用付费ASR接口，而是直接使用“语音评测API”返回的转写文本作为副产品。 | 极低（API自带） |
| **12** | 发布任务 | **极度简化**。教练端只有一个按钮：“**布置当前辩题**”，选择班级后，学生端首页自动出现该题。无复杂权重。 | 低（简单） |
| **13** | 查看学员数据 | **保留**。教练看板固定展示：**全班完成率**、**全班平均分**、**各维度强弱项柱状图**。 | 低（简单） |
| **14** | 查看个人档案 | **保留**。教练点击任何学生，直接查看其上述第4、5项的个人数据。 | 低（复用） |

### 🟡 清单二：V2.0 规划（延后迭代，共10项）
> **原则**：这些功能“听起来很好”，但依赖复杂交互或人工运营。**当前版本只建空表或预留接口，界面按钮先隐藏**，待项目通过验收后再开发。

| 序号 | 原功能名 | **延期理由与替代方案** |
| :--- | :--- | :--- |
| **1** | 即兴练习 | 当前AI实时生成延迟高。V2.0再做，目前仅内置**5套固定应急题库**供选。 |
| **15** | 人工复评 | 保留数据库字段，但V1.0教练暂不能改分。V2.0开放手动调节滑块覆盖AI分。 |
| **16** | 评语模板 | 教练在文本框复制粘贴即可，不开发独立模板库，用浏览器本地缓存暂存。 |
| **20** | 课程管理 | 不做多课程切换。**仅支持“当前班级”单一场景**，批量导入名单用Excel即可。 |
| **21** | 教学资源库 | 暂不开发。改用**云盘（百度网盘）链接**挂载在公告里。 |
| **24** | 作品提交 | V1.0录音**自动提交并存储**，无需学员手动点击“提交”按钮。 |
| **25** | AI初筛打分 | V1.0仅把AI评分展示给教练参考，不做“自动排序筛选”。 |
| **26/27**| 评委管理/多评委制 | 全部砍掉。V1.0 **只有一个教练角色**，没有“评委”概念。 |
| **28** | 评分标准自定义 | 固定使用平台预设的5维权重（发音30%，逻辑30%，流利度20%，词汇10%，反应10%），V2.0开放调整。 |
| **31** | 奖项管理 | 不做自动证书。**教练线下发奖状，线上只做Top3排行榜展示**。 |

### ⚫ 清单三：永久砍掉 / 触碰红线（共15项）
> **原则**：涉及**未成年人肖像权**、**高昂存储转码成本**、**社交/直播资质**、**极度复杂权限**。**V1.0至V3.0永不开发**，用第三方工具替代。

| 序号 | 原功能名 | **砍掉理由与替代方案（向老师汇报的话术）** |
| :--- | :--- | :--- |
| **7** | 视频录制 | 存储和带宽成本超预算，且涉及未成年人人脸隐私。**替代方案：仅录制音频（MP3）**，避免肖像权风险。 |
| **8** | 对标示范 | AI自动视频标注需要CV算法团队，学生团队无法实现。**替代方案：由教练手动上传优秀学生录音作为“示范音频”**。 |
| **10** | 社区分享 | 触碰微信小程序“社交-社区”类目红线，需额外ICP证且审核必拒。**替代方案：数据仅在班级内可见**，无公开广场。 |
| **18** | 一对一指导 | 涉及即时通讯（IM）和离线消息推送，开发量巨大。**替代方案：教练在“个人档案”下直接写入文字批注**，非私信。 |
| **19** | 提醒功能 | 微信模板消息限制严格且容易封禁。**替代方案：教练在企业微信群@未完成学员**，平台只显示红点。 |
| **22** | 创建比赛 | **过度设计**。辩论平台当前核心是“日常训练”，不是“举办大型赛事”。**彻底砍掉**。 |
| **23** | 报名管理 | 同上，彻底砍掉。 |
| **29** | 实时排行榜 | 实时聚合计算消耗数据库性能，且容易制造焦虑。**替代方案：仅展示个人最佳进步幅度**，不做全榜排名。 |
| **30** | 比赛直播/回放 | 需额外采购CDN和推流服务，且直播未成年人画面风险极大。**替代方案：使用腾讯会议直播**，平台只放录播网盘链接。 |
| **32/33**| 数据分析报告 / 多赛并行 | 依赖大量赛事数据，当前无数据源。**彻底砍掉**。 |
| **9** | 每日挑战 | 与“发布任务”功能高度重复，且机械打卡毫无意义。**合并进任务发布**。 |
| **11** | 收藏夹 | 数据量小，浏览器自带书签即可，无需开发。 |
| **17** | 优秀案例推荐 | 同第8条，改为教练手动置顶。 |

### 💡 给团队和导师的最终汇报话术

当导师问“为什么砍掉这么多功能”时，你可以直接说：

> *“我们基于‘未成年人保护合规’和‘6周极限开发’做了功能降级。**视频、直播、社区三大板块涉及肖像权和互联网资质，风险不可控，我们选择用音频+班级隔离替代**。当前V1.0版本虽然功能少，但完整跑通了‘**AI辅助写作 -> 语音评测 -> 数据量化对比**’的科研闭环，这恰恰是项目结题最需要的实证数据。砍掉的功能我们都在架构中预留了字段，未来可以无缝升级。”*
